# QuoteVault - Digital Bookshelf Library

Une application mobile Expo pour découvrir, rechercher et sauvegarder des citations inspirantes.

## 📱 Fonctionnalités

- **Authentification** : Connexion et inscription sécurisée
- **Citations aléatoires** : Découvrez de nouvelles citations chaque jour
- **Recherche** : Trouvez des citations par mot-clé ou auteur
- **Favoris** : Sauvegardez vos citations préférées en local
- **Profil** : Gérez votre compte et consultez vos statistiques

## 🛠️ Technologies utilisées

- **Expo** ^54.0.6
- **React Native** 0.81.5
- **React** 19.1.0
- **React Navigation** v7
- **SQLite** : Stockage local des données
- **Axios** : Communication avec l'API Quotable
